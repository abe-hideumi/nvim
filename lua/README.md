# lua/

vim 本体の設定。プラグインの spec は [`plugins/`](plugins/README.md) にある。

| ファイル | 役割 |
| --- | --- |
| `options.lua` | `vim.opt` / `vim.g` の設定 |
| `keymaps.lua` | vim 本体のキーマップ。プラグイン固有のものは各 spec の `keys` に置く |
| `autocmds.lua` | イベントに反応して自動で走る処理と、それを手動で叩くユーザーコマンド |

## オプション

`options.lua` で設定しているもの。

- `number` — 行番号を表示
- `tabstop` / `shiftwidth` = 4、`expandtab` — インデント幅4、タブはスペースに展開
- `ignorecase` + `smartcase` — 検索は大文字を含むときだけ大小を区別
- `clipboard = "unnamedplus"` — ヤンクをOSのクリップボードと共有

足したら上のリストにも1行足す。

## キーマップ

設定しているキーの一覧。leader キーは `<Space>`。

| キー | モード | 動作 |
| --- | --- | --- |
| `<C-h>` / `<C-j>` / `<C-k>` / `<C-l>` | n | 左 / 下 / 上 / 右のウィンドウへ移動 |
| `<leader>w` | n | 保存 |
| `<leader>q` | n | 終了 |
| `<leader>Q` | n | 全ウィンドウを終了（`:qa`） |
| `<leader>t` | n | 画面下にターミナルをトグル（高さ25）。バッファは使い回すので閉じても中身が残る |
| `<C-n>` | t | terminal モードを抜ける |
| `<C-d>` | n | Gitの差分をトグル（diffview。組み込みの半画面スクロールは潰れる） |
| `<C-f>` | n | ファイルを絞り込み検索（telescope。組み込みの1画面前スクロールは潰れる） |
| `<C-e>` | n | ウィンドウリサイズモードに入る（winresizer。組み込みの1行下スクロールは潰れる） |
| `j` / `k` | n | accelerated-jk（`gj` / `gk` ベースなので折り返し行も1行ずつ動く） |
| `gd` | n | 定義へジャンプ。LSP が attach したバッファでのみ有効 |

`keymaps.lua` に書くのは vim 本体のキーだけ。プラグイン固有のキーマップは
各 spec の `keys` に書く（[`plugins/README.md`](plugins/README.md)）。
定義はプラグインごとに散るので、どこに書いたキーも上の表に1行足して、探す場所はこの表に一本化する。

`K`（ドキュメント表示）と `gr*`（`grr` 参照一覧 / `grn` リネーム / `gra` コードアクション /
`gri` 実装 / `grt` 型定義）は Neovim 0.11+ の組み込み既定なので、ここには書かない
（`:h lsp-defaults`）。とくに `gr` を自分で割り当てると `gr*` と前方一致して
`timeoutlen` のぶん待たされるので割り当てない。

補完メニューのキーも、blink.cmp 側の `preset = "default"` が持っているのでここには書かない
（`preset` を捨てて全部を手で書き直すことになり、かえって追いにくくなるため）。
探す場所としてキーだけ控える。設定は [`plugins/blink-cmp.lua`](plugins/blink-cmp.lua)。

| キー | モード | 動作 |
| --- | --- | --- |
| `<C-n>` / `<C-p>` | i | 候補を次 / 前へ |
| `<C-y>` | i | 候補を確定 |
| `<C-e>` | i | 補完メニューを閉じる |
| `<C-space>` | i | 補完メニューを開く（閉じているとき）/ ドキュメントの表示切り替え |
| `<C-b>` / `<C-f>` | i | ドキュメントをスクロール |
| `<Tab>` / `<S-Tab>` | i | スニペットの次 / 前の入力欄へ |
| `<C-k>` | i | シグネチャヘルプの表示切り替え |

`<C-k>` と `<C-n>` は上の表にもあるが、モードが違うので衝突しない
（`<C-k>` はウィンドウ移動が n、シグネチャヘルプが i。`<C-n>` は terminal モード脱出が t）。

## autocmd

`autocmds.lua` で設定しているもの。

| イベント | 動作 |
| --- | --- |
| `VimEnter` | 異常終了した Neovim が残したスワップファイルのうち、救う中身が無いものを消す |

| コマンド | 動作 |
| --- | --- |
| `:SwapClean` | 上と同じ掃除を手動で走らせて、消したファイル名を表示する |

足したら上の表にも1行足す。

### スワップファイルの掃除

スワップ（`stdpath("state")/swap/`）はバッファを開いている間だけ存在し、
`:q` で正常終了すれば自動で消える。残るのはターミナルのウィンドウごと閉じた・
クラッシュした・`kill` されたなど、後片付けができなかったときだけ。
残ったままだと次に同じファイルを開くたび `Found a swap file` の確認が出る。

消すのは次を全部満たすものだけにしている。

1. このホストで作られた（スワップ先頭の `block0` に記録されたホスト名で判定）
2. 作成元のプロセスがもう居ない（同じく `block0` の PID に `kill(pid, 0)` を撃つ）
3. 元ファイルが今もある
4. ディレクトリバッファ（ファイラー表示）のもの、または元ファイルのほうが
   スワップより新しい

4 が効くので、クラッシュして未保存の変更が残っている本物のスワップは消えず、
復旧の確認はこれまでどおり出る。判定できないもの（PID が読めない、`kill` が
権限エラー）は生きている側に倒して触らない。PID が使い回されていた場合も
同じく残す側に倒れる。

`VimEnter` では通知を出さない。消す物が無いのが普通の状態で、毎回の起動画面を
汚すため。何が消えたか見たいときは `:SwapClean` を手で叩く。
